# B.L. Hissaria Jewellers

Professional luxury jewellery website built with React, Tailwind CSS, and React Router.

## Pages

| Route | Page |
|-------|------|
| `/` | Home (hero) |
| `/collections` | Collections |
| `/about` | About Us |
| `/craft` | Our Craft |
| `/contact` | Contact Us |

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite + React 19
- Tailwind CSS v4
- React Router v7
- Brand fonts: Cormorant Garamond + Outfit
